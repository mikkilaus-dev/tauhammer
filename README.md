# Tauhammer

Recent T'au Empire 40k tournament lists. Zero dependencies, needs Node 18+.

```
node server.js   # then open http://localhost:3000
```

- **Detachments tab:** undefeated / 1-loss lists with detachment and full list text (parsed from Listhammer's public T'au faction page).
- **BCP tab:** recent results from Best Coast Pairings (list text requires a BCP login, so entries link out).
